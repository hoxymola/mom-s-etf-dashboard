# ETF 자산 현황판 (로컬 전용)

부모님이 매일 손으로 적으시던 **종가 · 수익률 · 지수 · 배당**을 자동으로 채워 주는 프로그램입니다.
**ETF와 개별주식(코스피·코스닥) 모두** 됩니다.

인터넷에서 '가격만' 읽어올 뿐, 거래·주문 기능은 전혀 없습니다.
데이터는 이 폴더 안(`data/holdings.json`)에만 저장되고 어디에도 올라가지 않습니다.

---

## 1. 처음 한 번만: 설치 (설치해 주는 사람용)

1. PC에 **Python 3.10 이상**이 있어야 합니다.
   (없으면 https://www.python.org 에서 설치 → 설치 중 **"Add Python to PATH"** 체크)
2. 아래 한 줄로 필요한 라이브러리를 깝니다. (flask · finance-datareader · yfinance)
   ```
   pip install -r requirements.txt
   ```
   윈도우 `실행하기_Windows.bat`, 맥 `실행하기_Mac.command`가 **이 설치까지 자동으로** 해 주므로
   보통은 그냥 더블클릭만 하면 됩니다.

## 2. 매일: 실행 (부모님용)

- **윈도우**: `실행하기_Windows.bat` 더블클릭
- **맥**: `실행하기_Mac.command` 더블클릭

검은 창이 뜨고 잠시 뒤 **웹브라우저에 표가 자동으로 나타납니다.** (주소: http://127.0.0.1:5000)
끄실 때는 그 **검은 창**을 닫으면 됩니다. (브라우저만 닫으면 프로그램은 계속 켜져 있습니다.)

> 맥에서 "확인되지 않은 개발자" 경고가 뜨면: `실행하기_Mac.command` 우클릭 → 열기 → 열기.

## 3. 화면 안내

맨 위에는 **코스피 · 코스닥 · 나스닥 · S&P500 지수**와 **원/달러 환율**,
그리고 **총 평가금액 · 전체 수익률**이 나옵니다. 오른쪽 `↻ 새로고침`으로 다시 불러올 수 있습니다.

아래는 탭 4개입니다.

### 📋 보유 현황
맨 위에 **섹터 비중 막대**가 나오고, 그 아래 계좌별로
`섹터 · 수량 · 평단가 · 종가 · 수익률 · 비중 · 배당일자 · 배당/주 · 배당금 · 평가금액 · 평가손익`이
자동으로 채워집니다.

표에서 **클릭할 수 있는 칸**은 이렇습니다.

| 클릭할 곳 | 열리는 것 |
|---|---|
| **종목 이름** | 매수 / 매도 / 배당 창 |
| **수량 · 평단가** | 수정 창 (그 칸에 커서가 바로 놓입니다) |
| **섹터 태그** | 섹터 지정 창 (목록에서 고르거나 새 이름 직접 입력) |
| **배당/주** | 1주당 배당금 직접 입력 창 |
| **메모 · `+메모`** | 메모 수정 창 ("매도중" 같은 표시용) |
| **"코드 없음"** | 종목코드 찾기 창 |
| **표의 제목줄** | 그 열로 정렬 |

- **매수**: 수량과 (단가 또는 총금액)을 넣으면 **평단가를 가중평균으로 자동 재계산**합니다.
- **매도**: 수량만 줄이고 평단가는 그대로 둡니다.
- **배당**: 실제로 받은 금액을 적어 두면 배당 탭 합계에 들어갑니다.
- `🖨 보유 현황 인쇄`로 지금 화면을 A4에 담아 인쇄할 수 있습니다.
- 평단가가 비어 있으면 그 종목은 **계좌 합계·수익률 계산에서 빠집니다.** (기준이 없어서요)

#### 🏷 섹터 (반도체 · 바이오·헬스 · 자동차 · 미국지수 …)
종목코드에는 섹터 정보가 없습니다. 그래서 **종목 이름에 적힌 테마로 자동 분류**합니다.
(`TIGER 반도체TOP10커버드콜액티브` → 반도체, `PLUS 미국나스닥100미국채혼합50` → 채권혼합)

미리 아는 섹터는 18가지입니다.

| | |
|---|---|
| 업종·테마 | 반도체 · AI·빅테크 · 바이오·헬스 · 자동차 · 2차전지 · 원자력 · 우주항공 · 조선·해운 · 은행·금융 · 리츠·부동산 · 소비재 · 게임·엔터 |
| 지수·자산 | 미국지수 · 국내지수 · 배당·밸류 · 원자재 · 채권 · 채권혼합 |

- 자동 분류가 어색한 종목은 **섹터 태그를 클릭**해 바꾸면 그 종목만 고정됩니다.
  (예: `KIWOOM 미국S&P500&GOLD`는 지수와 금이 반씩 섞여 있어 원자재로 잡힙니다)
- **목록에 없는 이름을 직접 적어도 됩니다.** 한 번 쓰면 다음부터 목록에 나오고, 색도 자동으로 붙습니다.
  (`우주·방산`처럼 부모님이 쓰시는 말로 묶어도 됩니다)
- 직접 지정한 섹터에는 태그에 `✎`가 붙습니다. **비워 두고 저장**하거나
  **"자동 분류로 초기화"**를 누르면 자동 분류로 돌아갑니다.
- 맨 위 막대와 각 계좌 이름 옆의 `반도체 18.2% · …`는 **평가금액 기준 비중**입니다.

#### 📊 비중
`비중` 칸에는 위에 **그 계좌 안에서의 비중**, 아래 작은 글씨로 **전체 자산 대비 비중**이 나옵니다.

> 비중의 분모는 **평가금액이 계산된 종목 전부**입니다.
> 평단가를 안 넣은 종목은 수익률 계산에서는 빠지지만 비중에는 들어갑니다. (비중은 평단가와 무관하니까요)

#### ↕ 정렬
표의 **제목줄을 클릭**하면 그 계좌 표가 그 열로 정렬됩니다.
한 번 더 누르면 반대 순서, **세 번째로 누르면 원래 순서**로 돌아옵니다.

- 값이 없는 종목(시세 조회 실패 등)은 방향과 무관하게 **늘 맨 아래**에 놓입니다.
- 정렬은 **화면에서만** 바뀝니다. '종목 관리'에서 손으로 맞춰 둔 순서는 그대로 남습니다.
- 계좌마다 따로 정렬됩니다.

### 💰 배당
배당은 **자동으로 조회됩니다.** 종목의 배당(분배금) 이력을 찾아 새 배당이 생기면
`날짜 · 계좌 · 종목 · 금액`을 배당기록에 자동으로 넣어 줍니다. 월별·계좌별 합계와 전체 내역을 볼 수 있습니다.

- 날짜는 **배당락일 기준**이라 통장 입금일과 며칠 차이 날 수 있습니다.
- 금액은 **그 배당을 기록한 시점의 수량**으로 고정됩니다. (나중에 수량을 바꿔도 과거 배당금은 안 변합니다)
- 조회값이 실제와 다르면 **'보유 현황'의 `배당/주` 칸을 클릭**해 1주당 배당금을 직접 넣으면 됩니다.
  직접 넣은 값에는 ✎ 표시가 붙고, `초기화`를 누르면 다시 자동조회값을 씁니다.
- 실제로 받은 배당금은 **종목명 클릭 → 배당** 창에서 금액으로 적어 둘 수 있습니다.
- 처음 보는 종목은 **가장 최근 배당 1건만** 넣고 그때부터 추적합니다.
  (과거 이력을 몰아 넣으면 당시 수량과 안 맞아 부정확해서요)

### 📈 수익률
프로그램을 **열 때마다 그날 수익률이 자동으로 기록**됩니다. (버튼을 누를 필요 없습니다)
며칠 쌓이면 그래프와 `날짜 × 종목` 표가 채워집니다.

- 계좌 / 보기(종목별·계좌별) / 기간(1주·1개월·3개월·전체·직접입력)을 골라 볼 수 있습니다.
- `🖨 이 계좌 수익률표 인쇄`는 **선택한 계좌 하나만** 날짜가 가로로 나오는 표로 인쇄합니다.
- **국내 장이 열린 날에만** 기록합니다. (주말·공휴일에는 빈 날짜가 생기지 않습니다)

### ⚙️ 종목 관리
- **계좌 추가 · 이름 변경 · 삭제**를 할 수 있습니다.
  계좌 이름을 바꿔도 그동안의 배당 기록·수익률 그래프는 그대로 이어집니다.
  계좌를 삭제하면 **그 안의 종목과 배당 기록도 함께** 지워집니다.
- 계좌마다 `＋ 종목 추가` / `삭제`, 종목을 **드래그해서 순서 변경**.
- **종목코드가 있어야 시세가 자동으로 나옵니다.** 비어 있으면 "코드 없음"이 표시되고,
  그걸 누르면 **이름으로 검색**해서 넣을 수 있습니다. (ETF·개별주식 함께 검색됩니다 / 인터넷 필요)
- 코드가 들어가면 **종목명이 정식 이름으로 자동 교체**됩니다.

## 4. 가장 먼저 할 일 (중요)

처음엔 **종목코드와 평단가가 비어 있습니다.** 이 둘을 채워야 수익률이 나옵니다.

1. **종목코드**: '종목 관리' 탭에서 종목마다 `코드` 버튼 → 이름으로 검색 → 맞는 종목 선택.
   - 이름이 비슷한 게 많으니(위클리/데일리/타겟 등) 미래에셋 앱의 정확한 종목명과 대조해 주세요.
   - 코드는 **6자리**입니다. 개별주식은 숫자뿐이지만(`005930`), 최근 상장 ETF는 **영문이 섞입니다**(`0094M0`).
2. **평단가**: '보유 현황' 탭에서 평단가 칸을 클릭 → 미래에셋 앱의 평균단가를 입력.

한 번 채우면 계속 저장되므로, 다음부터는 그냥 실행만 하면 됩니다.

## 5. 자주 묻는 것

- **숫자가 앱이랑 달라요**
  → 이 프로그램은 **거래일 종가**까지 반영합니다. 장 마감 전이면 아직 오늘 종가가 없어서
  가장 최근 거래일 종가가 보일 수 있어요. (마감 후 조금 뒤에 채워집니다)
- **해외 지수가 – 로 나와요**
  → 미국장은 우리 시간 새벽에 끝나므로 아침에 채워집니다. 인터넷 연결도 확인해 주세요.
- **어떤 종목만 종가가 안 나와요**
  → 종목코드가 맞는지 확인해 주세요. 상장폐지·거래정지 종목은 값이 없을 수 있습니다.
- **검은 창에 `[배당 자동조회 불가] 475720 …` 같은 줄이 보여요**
  → 그 종목만 배당 이력을 못 받아 온 것입니다. 프로그램은 그대로 잘 돌아가니 걱정 안 하셔도 되고,
  그 종목의 `배당/주` 칸에 1주당 금액만 직접 넣어 주시면 됩니다.
- **배당이 안 잡혀요**
  → 최근 상장 종목은 배당 이력이 아직 없을 수 있습니다. 그럴 때는
  `배당/주` 칸에 1주당 금액을 직접 넣거나, 종목명 클릭 → 배당 창에 받은 금액을 적어 주세요.
- **미국 주식(SCHD, AAPL 등)도 되나요**
  → 지금은 **국내 상장 종목만** 됩니다. (금액을 모두 원화로, 코드를 6자리로 다루기 때문)
  국내 상장된 미국 지수 ETF는 물론 됩니다.
- **데이터가 날아갈까 걱정돼요**
  → 모든 데이터는 `data/holdings.json` 파일 하나에 들어 있습니다. 이 파일만 복사해 두면 백업됩니다.
  (프로그램이 저장할 때마다 `holdings.json.bak` 백업도 자동으로 만듭니다)

## 6. 폴더 구성

```
etf-dashboard/
├─ 실행하기_Windows.bat   ← 윈도우에서 더블클릭
├─ 실행하기_Mac.command   ← 맥에서 더블클릭
├─ app.py                 ← 프로그램 본체 (Flask 서버 + 시세·배당 조회)
├─ requirements.txt       ← 필요한 라이브러리 목록
├─ templates/index.html   ← 화면 (HTML·CSS·JS 한 파일)
└─ data/
   ├─ holdings.json         ← 내 종목·평단·배당 데이터 (여기만 백업하면 됨)
   ├─ holdings.json.bak     ← 저장할 때마다 자동 백업
   └─ holdings.example.json ← 빈 틀 (첫 실행 때 이걸 복사해 holdings.json을 만듭니다)
```

> `data/holdings.json`은 실제 자산 정보라 git에 올리지 않습니다(`.gitignore`).
> 저장소에는 빈 틀인 `holdings.example.json`만 들어 있습니다.

## 7. 개발자 메모

### 데이터 파일 구조 (`data/holdings.json`)
```jsonc
{
  "환율_USDKRW": null,
  "계좌": [
    { "계좌명": "일반계좌", "계좌번호": "", "설명": "국내 월 배당 생산지",
      "종목": [
        { "종목명": "KODEX 미국S&P500", "종목코드": "379800",
          "수량": 100, "평단가": 20000, "메모": "",
          "주당배당금수정": null,        // 넣으면 자동조회값 대신 이 값을 씀
          "섹터": null }                // 넣으면 이름 자동분류 대신 이 값을 씀
      ] }
  ],
  "배당기록": [
    { "날짜": "2026-07-30", "계좌명": "개인IRP", "종목명": "KODEX 미국S&P500",
      "금액": 13200, "주당분배금": 132, "메모": "자동조회(배당락일 기준)" }
  ],
  "수익률스냅샷": {
    "2026-08-18": { "총수익률": 12.3, "계좌": { "일반계좌": 8.1 },
                    "종목": { "일반계좌||KODEX 미국S&P500": 23.15 } }
  }
}
```

### 외부 데이터 소스
| 항목 | 소스 | 비고 |
|---|---|---|
| 종가 | `FinanceDataReader.DataReader(코드)` | ETF·개별주식 구분 없이 동작 |
| 종목 목록 | `StockListing("ETF/KR")` + `StockListing("KRX")` | 약 1,100 + 2,900 = 4,000여 종목 |
| ETF 분류 | 같은 목록의 `Category` 컬럼 (1~7) | 섹터 자동분류의 **마지막 폴백**으로만 씀 |
| 배당 이력 | `yfinance.Ticker(코드 + 접미사).dividends` | 코스피 `.KS` / 코스닥 `.KQ` (코넥스 등 불명이면 둘 다 시도) |
| 지수 | `KS11` `KQ11` / `IXIC` `US500` 등 | 후보를 앞에서부터 시도 |
| 환율 | `USD/KRW` → `USDKRW=X` | 앞이 실패하면 뒤로 |

- 모든 외부 조회는 **일회용 스레드 + 8초 타임아웃**(`FETCH_TIMEOUT`)으로 감싸서,
  한 소스가 멈춰도 화면이 멈추지 않습니다.
- 가격 · 배당 이력 · 종목 목록은 **하루 한 번만** 조회하고 메모리에 캐시합니다.
- 종목코드는 저장·조회 시 `norm_code()`로 **공백 제거 + 대문자**로 통일합니다.
  (`0094m0` → `0094M0` — 목록 사전이 대문자 기준이라 안 맞추면 이름·시장 조회가 어긋납니다)

### 계산 규칙
- 종목 수익률 = `(종가 - 평단가) / 평단가 × 100`
- 계좌·전체 수익률 = `(평가금액합 - 원가합) / 원가합 × 100`
  → **평단가가 없는 종목은 합계에서 제외**됩니다.
- 스냅샷은 `_is_market_open_today()`(코스피 최신 거래일 == 오늘)일 때만 기록하고,
  같은 날 여러 번 열면 **마지막 값으로 갱신**합니다.
- 배당 자동감지는 종목별로 **이미 기록된 가장 최근 날짜 이후**만 추가하므로,
  직접 입력해 둔 과거 기록은 건드리지 않습니다.
- 비중 = `평가금액 / 비중기준금액 × 100`
  → 분모 `비중기준금액`은 **평가금액이 계산된 종목 전부**의 합입니다.
    수익률용 `평가금액합`(평단가 있는 종목만)과 **일부러 다릅니다** — 비중은 평단가와 무관하니까요.
- 섹터는 `SECTOR_RULES`(app.py)의 **위에서부터 먼저 걸리는 키워드가 이깁니다.** 순서가 규칙입니다.
  업종·테마 규칙이 모두 위에 있고, 넓게 걸리는 지수 규칙(`200`·`코리아` 등)이 맨 아래입니다.
  - `미국우주항공` → 미국지수보다 우주항공이 먼저
  - `200헬스케어` → 국내지수(`200`)보다 바이오·헬스가 먼저
  - `금융고배당TOP10` → 은행·금융 규칙에 `금융`을 **일부러 넣지 않아** 배당·밸류로 갑니다
  - 규칙을 고칠 때는 **보유 종목 전체의 분류가 안 바뀌는지 먼저 돌려 보세요.**
    (`classify_sector(이름, 코드)`를 46종목에 한 번 돌리면 됩니다)
- 섹터 선택 목록(`sector_options`)은 **규칙에 있는 이름 + 지금 실제로 쓰이는 이름**입니다.
  화면에서는 `<input list=…>`(datalist)라 목록에 없는 이름도 그냥 적을 수 있고,
  한 번 저장되면 그 이름이 목록에 자동으로 들어옵니다. 색은 이름을 해시해 정하므로 새로고침해도 같습니다.
  영문 약어(`AI`·`GOLD`)는 다른 영단어 속에 우연히 끼는 걸 막으려고 **앞뒤가 영문자가 아닐 때만** 인정합니다
  (`DAILY` 안의 `AI`를 AI 테마로 잡지 않도록).
  종목의 `섹터` 필드가 있으면 규칙을 건너뜁니다.
- 표 정렬은 **화면 상태(JS `SORT`)일 뿐 저장하지 않습니다.** `/api/holding/reorder`로 맞춘 수동 순서가 원본입니다.

### 아직 안 되는 것
- 해외 상장 종목(미국 티커) — 원화 전제 + 6자리 코드 전제
- 실시간(장중) 가격 — 종가 기준입니다
- 세금·수수료 반영, 매매 이력 저장 (평단가만 갱신)
