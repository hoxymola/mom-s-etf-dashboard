# ETF 자산 현황판 (로컬 전용)

부모님이 매일 손으로 적으시던 **종가 · 수익률 · 지수 · 배당**을 자동으로 채워 주는 프로그램입니다.
인터넷에서 '가격만' 읽어올 뿐, 거래·주문 기능은 전혀 없습니다. 데이터는 이 폴더 안에만 저장되고 어디에도 올라가지 않습니다.

---

## 1. 처음 한 번만: 설치 (설치해 주는 사람용)

1. PC에 **Python 3.10 이상**이 설치돼 있어야 합니다. (없으면 https://www.python.org 에서 설치 → 설치 중 "Add Python to PATH" 체크)
2. 이 폴더에서 아래를 한 번 실행해 필요한 것들을 깝니다.
   ```
   pip install -r requirements.txt
   ```
   (윈도우는 `실행하기_Windows.bat`, 맥은 `실행하기_Mac.command`가 이 설치까지 자동으로 해 줍니다.)

## 2. 매일: 실행 (부모님용)

- **윈도우**: `실행하기_Windows.bat` 더블클릭
- **맥**: `실행하기_Mac.command` 더블클릭

검은 창이 뜨고 잠시 뒤 **웹브라우저에 표가 자동으로 나타납니다.**
끄실 때는 그 검은 창을 닫으면 됩니다. (브라우저만 닫으면 프로그램은 계속 켜져 있습니다.)

> 맥에서 "확인되지 않은 개발자" 경고가 뜨면: `실행하기_Mac.command`를 마우스 우클릭 → 열기 → 열기.

---

## 3. 쓰는 법

### 오늘의 시세 탭
- 계좌별로 보유 종목의 어제종가·오늘종가·수익률·평가금액이 자동으로 나옵니다.
- 위쪽에 코스피·코스닥·나스닥·S&P500 지수가 자동으로 나옵니다.
- **수량이나 평단가를 클릭하면 바로 고칠 수 있습니다.** → 추가 매수·매도를 하면 여기서 숫자만 바꾸면 됩니다.

### 배당 탭
- 배당은 자동으로 못 가져옵니다(통장 입금액이라서요). 미래에셋 앱에서 확인해 날짜·계좌·금액을 적어 두면 월별·계좌별로 자동 합산됩니다.

### 수익률 그래프 탭
- 매일 상단의 **"오늘 수익률 기록"** 버튼을 누르면 그날 수익률이 저장됩니다. 며칠 쌓이면 그래프가 그려집니다.

### 종목 관리 탭
- **종목코드(6자리)가 있어야 시세가 자동으로 나옵니다.**
- 코드가 비어 있으면 "코드 없음" 표시가 뜹니다. 그걸 누르고 이름으로 검색해 코드를 넣으면 됩니다. (인터넷 연결 필요)

---

## 4. 가장 먼저 할 일 (중요)

처음엔 **종목코드와 평단가가 비어 있습니다.** 이 둘을 채워야 수익률이 나옵니다.

1. **종목코드**: '종목 관리' 탭에서 종목마다 "코드" 버튼 → 이름으로 검색 → 맞는 종목 선택.
   - 이름이 비슷한 게 많으니(위클리/데일리/타겟 등) 미래에셋 앱의 정확한 종목명과 대조해 주세요.
2. **평단가**: '오늘의 시세' 탭에서 평단가 칸을 클릭 → 미래에셋 앱의 평균단가를 입력.

한 번 채우면 계속 저장되므로, 다음부터는 그냥 실행만 하면 됩니다.

---

## 5. 자주 묻는 것

- **숫자가 앱이랑 달라요** → 이 프로그램은 '전일 종가'까지 반영합니다. 장 마감 전이면 아직 오늘 종가가 안 나올 수 있어요(마감 후 조금 뒤에 채워집니다).
- **해외 종가가 –로 나와요** → 미국장은 우리 시간 새벽에 끝나므로 아침에 채워집니다. 인터넷 연결도 확인해 주세요.
- **데이터가 날아갈까 걱정돼요** → 모든 데이터는 `data/holdings.json` 파일 하나에 들어 있습니다. 이 파일만 복사해 두면 백업됩니다. (프로그램이 저장할 때마다 `holdings.json.bak` 백업도 자동으로 만듭니다.)

---

## 폴더 구성
```
etf-dashboard/
├─ 실행하기_Windows.bat   ← 윈도우에서 더블클릭
├─ 실행하기_Mac.command   ← 맥에서 더블클릭
├─ app.py                 ← 프로그램 본체
├─ requirements.txt       ← 필요한 라이브러리 목록
├─ templates/index.html   ← 화면
└─ data/holdings.json     ← 내 종목·평단·배당 데이터 (여기만 백업하면 됨)
```
